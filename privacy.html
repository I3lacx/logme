Privacy policy

Last updated: 27 October 2026

LogMe is a private, single-user application operated by Maximilian Otte for his own use. It is not offered to the public.

What data is accessed

With explicit consent given through Google's sign-in screen, LogMe reads the signed-in user's own data from the Google Health API using these read-only scopes:

  • Activity and fitness (for example steps, distance, active zone minutes)
  • Health metrics and measurements (for example resting heart rate, heart-rate variability, oxygen saturation, breathing rate, weight)
  • Sleep (sleep duration and sleep stages)

LogMe never writes, changes or deletes data in Google Health.

How the data is used

The data is used only to show the user his own daily values and charts next to his own manually entered notes and measurements. It is not used for advertising, profiling, selling, or training of any model.

Where the data is stored

Daily summaries are stored in a database on the user's own home server, which is reachable only from his home network. Encrypted backups of that database are stored in the user's own cloud storage. Access tokens are stored on the home server only.

Sharing

The data is not shared with, sold to, or transferred to any third party.

Google API Services User Data Policy

LogMe's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions. Stored data can be deleted on request by email.
