LogMe

A private, single-user daily tracker for health habits, symptoms and notes.

LogMe is a personal project. It runs on its owner's own home server and is used by one person only. It records daily values (for example pain scores, stretching progress and habits), a daily note and events, and shows them as charts over time.

Google Health data

With the owner's explicit consent, LogMe reads his own activity, sleep and health-metric summaries (such as steps, sleep duration, resting heart rate and heart-rate variability) from the Google Health API with read-only access. The data is stored only on the owner's home server so he can compare it with his own daily notes. LogMe never writes to Google Health and never shares the data.
